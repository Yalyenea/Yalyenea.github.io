AI / Models / Agents

Learning more about Claude’s mathematical capabilities — Anthropic describes how an unreleased Claude research model raised the verified lower bound on the proportion of Riemann zeta zeros satisfying the hypothesis from 41.6% to 67.2%, with a paper and Lean formalization.

Dyna-2: A 1-Million-Hour Scaling Law for World-Action Models — Dyna Robotics presents a world-action model pretrained on more than one million hours of human video and studies its scaling behavior on human and robot tasks.

[2608.09867] Stealing Reasoning Traces from Proprietary LLM APIs — demonstrates how reusing encrypted reasoning blocks across sessions may expose proprietary reasoning traces, and discusses prompt-injection risks and mitigations.

Introducing Unsloth Desktop — an open-source desktop application for Windows, macOS, and Linux that runs, trains, exports, and deploys several kinds of AI models locally.

MiniMaxAI/MiniMax-Music3 · Hugging Face — MiniMax’s model and weights page for its music-generation model.

Training AI Scientists to Replicate Research · Inherent — introduces Faraday, a 27B AI research agent trained with long-horizon reinforcement learning to reproduce figures from research papers.

Measuring Autonomous AI Research — reports an evaluation of 18 frontier models across 153 autonomous runs on a nanoGPT optimizer speedrun task.

SlimeBoyOwO/LingChat — an AI-powered galgame chat application with expressive characters, a desktop pet, scheduling, and interactive story modules.

Mathematics / Research / Learning

Problems · TheoremDB — a database of mathematics and theoretical computer science problems filterable by field, solution status, and Lean verification status.

[2606.03953] Introduction to stochastic gradient methods — a systematic introduction to deterministic and stochastic first-order optimization, covering smoothness, convexity, the PL condition, convergence rates, and variance reduction.

ComfyResearch: See How Learning Happens — represents data, models, training, and observations as composable graph nodes so researchers can visualize and compare neural-network learning dynamics.

Hadamard Matrix of Order 668 | Epoch AI — a FrontierMath problem on constructing a Hadamard matrix of order 668; the page records a candidate solution developed collaboratively by three researchers and Claude.

Matrix Calculus — an online symbolic tool that differentiates vector, matrix, and tensor expressions and exports results to Python or LaTeX.

  • [2010.03313] A Simple and Efficient Tensor Calculus for Machine Learning — proposes an Einstein-notation-based tensor differentiation algorithm designed for efficient higher-order derivatives and automatic-differentiation representations.
  • Computing Higher Order Derivatives of Matrix and Tensor Expressions — presents a framework for directly computing higher-order matrix and tensor derivatives using symbolic, forward, and reverse automatic differentiation.

GENO — describes optimization problems in a modeling language and automatically generates Python solvers for CPUs or GPUs.

  • [1905.13587] GENO — GENeric Optimization for Classical Machine Learning — introduces the GENO framework for generating specialized solvers from declarative problem descriptions and evaluates it on classical machine-learning problems.
  • [2203.16340] Optimization for Classical Machine Learning Problems on the GPU — extends GENO to constrained GPU optimization and compares solver performance across classical machine-learning problems.

How to keep thinking — considers how frequently reviewing LLM output can affect habits of slow thought, and recommends writing and reading dense books to preserve deeper thinking.

Free eBooks | Project Gutenberg — a free ebook library focused primarily on older works whose U.S. copyrights have expired.

Sakai Association of Science Summer Training 2026 — the 2026 summer training course site for publishing preparatory material, lecture notes, and assignments.

ChapterPal — AI-assisted reading and note-taking — an AI-assisted reading and note-taking tool with contextual Q&A, active recall, and incremental reading.

Math Translations — a community for openly preserving, sharing, and collaboratively maintaining Chinese translations of mathematics texts, lecture notes, and terminology.

Algorithm Wiki — a knowledge base that organizes algorithm material by field, problem, algorithm family, and variant.

lassejlv/gpui-starter — a minimal Rust desktop application template built with Zed’s GPUI, including a basic theme and interaction example.

raullenchai/Rapid-MLX — a local model-serving engine for Apple Silicon with OpenAI- and Anthropic-compatible APIs for coding agents and other clients.

Waku — one native app for all your coding agents — a native Rust and GPUI application that manages sessions, tool activity, and Git checkpoints for multiple coding agents in one interface.

pytorch-training-recipe · ml-training · pytorch-lightning — three agent skills for training workflows, covering reproducible PyTorch training, general machine-learning checks, and PyTorch Lightning project organization.

DeepSeek Harness — DeepSeek’s open-source agent runtime with an everything-is-a-plugin architecture, currently in developer preview.

Package Catalog · Pi — a catalog of npm-distributed extensions, skills, prompt templates, and themes for the Pi coding agent.

zhu1090093659/dsh-web-ui — a community collection of plugins and skins for the DeepSeek Harness Web UI, including a task board, Git graph, and mobile remote interface.

kenn-io/agentsview — a local-first tool for searching and analyzing coding-agent sessions and token usage.

Zeron — monitors and controls local Claude Code, Codex, Grok, Hermes, and Pi agents from another device in real time.

blader/humanizer — an agent skill for reducing common signs of AI-generated prose.
