Learning more about Claude’s mathematical capabilities：Anthropic 介绍未发布的 Claude 研究模型如何把已验证满足黎曼猜想的零点比例下界从 41.6% 提高到 67.2%，并给出论文与 Lean 形式化结果。

Dyna-2: A 1-Million-Hour Scaling Law for World-Action Models：Dyna Robotics 介绍以超过 100 万小时人类视频预训练的世界—动作模型，并研究其在人类与机器人任务上的尺度规律。

[2608.09867] Stealing Reasoning Traces from Proprietary LLM APIs：论文展示跨会话复用加密推理块可能泄露专有模型的推理内容，并讨论提示注入风险与缓解方案。

Introducing Unsloth Desktop：跨 Windows、macOS 与 Linux 的开源桌面应用，用于本地运行、训练、导出和部署多类 AI 模型。

MiniMaxAI/MiniMax-Music3 · Hugging Face：MiniMax 发布的音乐生成模型及权重页面。

Training AI Scientists to Replicate Research · Inherent：介绍 Faraday：以复现论文图表为任务、经长时程强化学习训练的 27B AI 科研 agent。

Measuring Autonomous AI Research：报告在 nanoGPT 优化器速跑任务上对 18 个前沿模型进行 153 次自主运行的评测。

SlimeBoyOwO/LingChat：带情感表现、桌宠、日程与互动剧情模块的 AI Galgame 聊天应用。

数学 / 科研 / 学习

Problems · TheoremDB：收录数学与理论计算机科学问题的数据库，可按领域、解决状态与 Lean 验证状态筛选。

[2606.03953] Introduction to stochastic gradient methods：系统介绍确定性与随机一阶优化方法，涵盖光滑性、凸性、PL 条件、收敛率与方差缩减。

ComfyResearch: See How Learning Happens：用可组合图节点表示数据、模型、训练和观测，帮助研究者可视化并比较神经网络的学习动态。

Hadamard Matrix of Order 668 | Epoch AI：FrontierMath 的 668 阶 Hadamard 矩阵构造问题；页面记录了一个由三名研究者与 Claude 协作得到的候选解。

Matrix Calculus：可计算向量、矩阵与张量表达式导数并导出 Python 或 LaTeX 的在线符号工具。

  • [2010.03313] A Simple and Efficient Tensor Calculus for Machine Learning：提出基于 Einstein 记号的张量求导算法，兼顾自动微分表示与高阶导数计算效率。
  • Computing Higher Order Derivatives of Matrix and Tensor Expressions：提出直接计算矩阵与张量高阶导数的框架，支持符号、前向和反向自动微分。

GENO：通过建模语言描述优化问题，并自动生成可在 CPU 或 GPU 上运行的 Python 求解器。

  • [1905.13587] GENO — GENeric Optimization for Classical Machine Learning：介绍由声明式问题描述自动生成求解器的 GENO 框架及其在经典机器学习优化问题上的表现。
  • [2203.16340] Optimization for Classical Machine Learning Problems on the GPU：将 GENO 扩展到 GPU 约束优化，并比较多类经典机器学习问题的求解效率。

How to keep thinking：讨论频繁审阅 LLM 输出对慢思考习惯的影响，并建议通过亲自写作和阅读高密度书籍保持深度思考。

Free eBooks | Project Gutenberg：以美国版权已到期的旧作品为主、可在线阅读或下载的免费电子书库。

酒井科协暑培 2026：2026 年暑期培训课程主页，用于集中发布准备材料、讲义与作业。

ChapterPal — AI-assisted reading and note-taking：提供上下文问答、主动回忆与渐进阅读功能的 AI 辅助阅读和笔记工具。

数译 · Math Translations：公开保存、分享和共同维护中文数学译本、讲义与术语表的社区。

Algorithm Wiki：按领域、问题、算法家族与变体组织算法资料的知识库。
