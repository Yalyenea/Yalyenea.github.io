AI / 模型 / 智能体

math-ai-org/mathcode：集成 Lean 的终端数学编程 agent，可检查证明目标、搜索声明、验证候选证明并交互式完成形式化证明。

Cua：为 computer-use agent 提供 GUI 沙箱与可扩展计算机集群，支持本地及托管部署。

Introducing Delta：Zed 推出的多人 agent 编程与审查环境，将代码、对话和工作树实时同步，让人类与 agent 共享开发上下文。

PyTorch: a reference language：提议将 PyTorch 保留为可执行参考规范，由 LLM 生成显式前向与反向实现并验证二者等价，也引出了 LLM 编写反向传播能否在部分场景取代自动微分的问题。

wibus-wee/cradle-app：桌面优先的 AI agent 管理平台，可统一运行 agent、跟踪任务与会话、协调工作流并接入多个模型提供商。

Building a distributed training framework from first principles：Umar Jamil 从基本原理出发讲解如何构建分布式模型训练框架；此处仅依据公开视频标题与作者信息概括。

Ornith-1.5: From Self-Scaffolding to Self-Improvement：让模型自行生成训练任务、任务脚手架和解题轨迹，再通过强化学习形成持续自我改进闭环。

Famous Deep Learning Papers：按时间梳理深度学习经典论文，并概括每篇论文的核心问题与历史影响。

CS 8803 - LLM：Georgia Tech 2026 春季大语言模型课程主页，汇集预训练、推理、对齐等主题的讲义、论文与学生报告。

Papers with Code：按任务浏览机器学习论文、代码实现与基准结果的索引页。

CopilotKit/openbot：开源 AI 同事平台，为每个 agent 提供独立浏览器、文件与工具环境，并记录其决策和操作。

Machine Studying：提出让 agent 仅从文档语料自主形成领域专长的“Machine Studying”，并以 StudyBench 探索和衡量这一能力。

Hot Take: LLM can ‘jump’：主张互联知识可让模型沿不同于人类直觉的推演路径实现科学跃迁，并讨论安全与持续学习影响。

[2608.08003] The Spectral Neuron：通过仿射矩阵的特征值引入显式非线性，在模型表达力、系数透明度与形状约束之间寻求折中。

Learn Inference：以交互方式讲解生成式 AI 的生产推理工程，从注意力 kernel 延伸到多云容量规划。

The Year in AI Papers: Essential Research from 2025–2026：按主题、实验室、引用、代码和日期整理 2025–2026 年重要 AI 论文及简明摘要。

Marin 训练启动：Harrier K40 数据概览展示 23.11T token 在 40 个语义领域与 5 个质量桶中的分布；535B-A23B 18T Token Hero Run 报告与公开跟踪议题记录模型规格、缩放阶梯、训练动力学和风险监测方案。

数学 / 科研 / 学习

Fanout：汇集 AI 研究、系统设计与机器学习数学课程、路线图、论文解读及交互实验的技术学习平台。

Awesome Physics of AI：按学习动力学主题整理利用物理学原理理解、预测和解释深度学习的论文与研究脉络。

[2608.16884v1] Improving the matrix multiplication exponent with modern optimization and AlphaEvolve：结合优化问题重构、机器学习算法与 AlphaEvolve，将矩阵乘法指数的已知上界从 2.371339 改进至 $\omega < 2.371177$。

Classic Patents：开源历史技术专利博物馆，提供校验后的专利文本、原始 PDF、工程解析和交互式 3D 物理模拟。

How to Read a Technical Paper：建议先限时略读再精读，并边读边用自己的话记录、质疑和构想拓展；LLM 可辅助总结及检索后续评价，具体推敲仍应由读者完成。

Lean formalization of bounded gaps between primes：用 Lean 4 形式化验证有无穷多对相邻素数满足 $p_{n+1} - p_n \leq 246$ 的有界素数间隔定理。

CS229 Course Notes：Stanford CS229 的机器学习课程讲义，系统覆盖监督学习、学习理论、无监督学习与强化学习等基础。

[2608.16753] Mathematics in the age of AI：陶哲轩讨论研究级 AI 到来后，数学共同体应如何重新审视数学研究的目标与价值。

VibeMathed：社区整理此前无人解决、后来由 AI 参与证明或证伪的数学问题，并附可核验来源与验证标签。

形式化数学平台：lemma.ing记录数学问题、推导与研究进展，Halmos由 Lean 内核核验用户提交的证明，TheoremDB保存开放问题、证明、失败尝试与贡献归属，ProofAtlas提供定理解释、Lean 陈述和源码，Proof.Fail则用失败案例刻画 LLM 数学能力的边界。

Omarchy Plugins：Omarchy Quattro 的独立社区插件目录，可浏览源码并复制安装命令；核对时页面尚未收录插件。

kenneth’s gitea：Kenneth 自托管的 Gitea 实例，用于公开托管和浏览 Git 仓库。

[2608.13759] GPU Offload in Rust: Portable, Safe, and Fast：提出内置于 rustc 与 LLVM 后端的多厂商 GPU 编译框架，在保留 Rust 内存安全的同时取得接近 CUDA、HIP C++ 的 kernel 性能。

如何在 Rust 中开始使用 CPU 和 GPU：面向 Web 开发者、通过 Rust 代码讲解 CPU 与 GPU 工作原理的日文开源教材。

Linux Fundamentals：免费 Linux/Unix 基础教材，覆盖命令行、文件系统、进程、网络和 Shell 等核心知识。

VibeHub：用通俗语言和可视化方式解释 Vibe Coding 中前端、后端、技术栈及 AI 等常见术语。

Mojo 全面开源 · Mojo Manual：Mojo 以 Apache 2.0 许可证全面开源；官方手册系统介绍语法、类型、内存与异构硬件编程，也适合作为比较 Mojo、Triton、CUDA 与 TileLang 定位的起点。

OJO：由多个 AI 设计 agent 协作的产品工作台，可从自然语言需求推进到研究、UI、交互原型、代码及开发交付。

任意规模的 Git：Cursor 回顾大规模 Git 托管的存储与一致性难题，并介绍以 S3 写前日志为核心的 Continuity 架构。

Computer History Preview：Cua Driver 的实验性功能，会加密记录操作元数据，并允许获授权的 agent 只读查询最近历史。

cathrynlavery/diagram-design：面向 Claude Code、Codex 等编程 agent 的编辑风格制图技能，可生成多类自包含 HTML 与 SVG 图表并套用项目品牌样式。

fx：用 Zig 编写的轻量开源 coding agent CLI，强调约 6 MB 体积、快速启动、低上下文开销和可嵌入性。

Ladybird：由非营利组织支持、独立开发浏览器引擎与完整 Web 技术栈的开源浏览器项目。

Zellij.online：直接把 Zellij 终端会话分享至网页，无需 SSH、端口转发或额外网络配置。

Briq：面向 Windows 11 的原生 agent 辅助开发工作区，用于并行管理多个 coding agent。

OpenLogi：Rust 编写、本地优先的 Logitech Options+ 替代品，可通过 HID++ 重映射按键并控制 DPI 与 SmartShift，无账号和遥测。

terminal-code · zenbu-labs/terminal-code：把 VS Code 工作区带入终端的开源开发工具。

debpalash/VoiceStudio：完全本地、开源的 ElevenLabs 替代品，支持声音克隆、配音、听写、转录和有声书制作等功能。

Subdomain Enumeration via Certificate Transparency：利用公开 Certificate Transparency 数据被动枚举域名的已知子域，并给出首次出现日期。

fross100/omaplug：独立 Omarchy 插件管理器，可启停、更新、安装和移除插件。

lijiawei0305-pixel/omarchy-mihomo-plugin：为独立 mihomo 内核提供状态栏显示的 Omarchy 插件。

Arcotype：用于发现非泛用字体的精选目录，收录字体均可按 SIL Open Font License 免费使用。

Tuval：将安卓平板变成电脑数位板的开源工具，支持压感、倾斜、悬停、低延迟传输及画面镜像。

starcat-app/Starcat：原生 macOS GitHub Stars 管理器，通过标签、笔记、全文与语义搜索、AI 摘要等功能把收藏仓库整理成个人知识库。

Normal Tools：无需账号和下载、直接在浏览器运行的 193 个计算器、转换器、检查器、生成器与硬件测试工具。
